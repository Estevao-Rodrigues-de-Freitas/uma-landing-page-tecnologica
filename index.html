Introdução

Este template emula um site focado em serviços de tecnologia, utilizando das linguagens HTML, JavaScript e CSS para criar um site responsivo e com boa estilização, sem o uso de nenhuma biblioteca. O objetivo desse projeto é simplismente testar conhecimentos sobre interface, quanto a composição de elementos, utilizando de imagens e vídeos. Todas os assests desse site foram criados por mim Estevão Rodrigues de Freitas, utilizando do photoshop, paint tool SAI e o Blender.

NOSSA HISTÓRIA

Este campo é dedicado a contar a história da empresa, comentando sobre a criação do negócio, quantidade de clientes e funcionários, qualidade de serviço, dificuldades e propostas futuras. O campo muito importante para demonstrar a abertura que a empresa tem ao pubilico, uma maneira de humanizar o ambiente atuado pela empresa para a ótica das pessoas que podem ou pretendem ter algum contato.

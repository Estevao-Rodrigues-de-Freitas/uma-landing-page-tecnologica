# UMA LANDING PAGE TECNOLOGICA

---

## Descrição

Um modelo de template cujo representa uma landing page moderna e responsiva, focada em um site de tecnologia.

Este projeto emula uma interface de um site de tecnologia. Tudo foi criado pensado em telas de desktop, e depois foi adaptado para dispositivos menores.

---

## Tecnologias Utilizadas:

- HTML5  
- CSS3  
- JavaScript  
- Google Fonts
- Photoshop (para criação de imagem)
- Blender (para criação de vídeo)

## Explicação das Seções
### 1. Hero
- Entrega uma descriação básica do site
- Um botão que avança para área de serviços

### 2. Serviços
- Apresenta um espaço que organiza os serviços prestados

### 3. Nossa História
- Entrega um campo o qual é utilizado para contar a história da empresa

### 4. Confiado Por
- É um campo de parecerias, o qual indica o logo das empresas que estão conectadas na rede da empresa
